# 企业研究分析框架

研究企业先研究行业，再放到产业链里定位，最后回到公司本身。本技能用于拆解核查点、组织采集关键词、归类主张与检查遗漏。

## 七个核查模块

1. 行业与产业链
   - 行业整体：过去发展历史、现状、未来趋势；行业规模与增速。
   - 产业链上中下游：各环节成本、利润分布、议价能力；公司所处环节与位置。
   - 竞争格局：主要玩家、市场份额、集中度；公司与行业平均的比较维度。
2. 政策环境
   - 主管部门与行业协会、相关法律法规与硬性条款、近期规则变化。
   - 政策对行业需求、成本、准入、定价的传导路径。
3. 公司历史/治理与团队
   - 成立时间、注册资本、主营业务、发展历史；股权结构与变化。
   - 核心团队（CEO/CTO/CFO/董事/董监高）：教育背景、从业经历、任职时长与稳定性。
4. 核心技术能力
   - 研发投入与核心能力、生产工艺变化与提升。
   - 壁垒：独立性、排他性、不可替代性、知识产权/专利。
5. 产品与市场
   - 产品竞争力与溢价能力、市场占有率、利润稳定性。
   - 横向拓展能力：核心板块向相关板块的衍生。
6. 财务表现
   - 资产负债率、利润水平/利润率、逐月/逐年变化。
   - 收入来源构成与可持续性；与行业平均对比（高/低及原因）。
7. 抗风险与综合研判
   - 现金流、偿债与融资能力、关键风险点。
   - 综合研判：区分“已证实事实”与“分析性观察”，观察须标注依据与不确定性。

## 使用方式

- 拆解任务时：按以上模块生成核查点，避免只盯财务数字。
- 采集时：每个模块至少覆盖一类公开信源（年报/招股说明书/公告/研报/行业数据/官方统计）。
- 归类主张时：category 使用模块名（行业与产业链/政策环境/公司治理与团队/技术核心能力/产品与市场/财务表现/风险与不确定性/其他）。
- 复核时：检查跨模块一致性、指标口径与时间范围是否统一、是否与行业平均做了比较。
- 参考文档：上市公司的“年报”（年度报告，含经营与财务）和“招股说明书”（企业研究框架范本）。
