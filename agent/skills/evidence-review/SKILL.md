# 证据复核技能

当用户要求对研究结论、底稿或一组主张做证据复核时使用本技能。

## 执行步骤

1. 把待复核的每条主张拆成独立条目并编号。
2. 对每条主张回查底稿/证据中对应的原文依据；证据不足时明确标注“证据不足”。
3. 按以下维度输出核验意见：
   - 主张原文
   - 依据来源（链接或文档位置）
   - 来源可信度：高 / 中 / 低，并说明理由
   - 是否存在冲突证据
   - 建议结论：保留 / 修改 / 排除 / 补充取证
4. 汇总所有条目结论，优先列出需要人工复核的疑点。
5. 全程不臆造来源；找不到依据时如实说明。

## 注意事项

- 本技能为纯指令型技能：按上述步骤使用已有工具（web、memory、document 等）完成复核。
- 输出使用中文，先给汇总结论，再给逐条明细。
